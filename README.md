# شغل الدقهلية | منصة الوظائف الحقيقية

منصة عربية متوافقة مع الموبايل لعرض فرص العمل في المنصورة والقرى الواقعة على الخط حتى دكرنس، مع التقديم المباشر عبر واتساب.

## المميزات الموجودة في المشروع

- واجهة عربية من اليمين إلى اليسار ومتجاوبة مع شاشات الموبايل.
- إضافة الوظائف وإرسالها للمراجعة قبل النشر.
- تصفح الوظائف والبحث والتصفية حسب التصنيف والمنطقة والترتيب.
- اختصارات للتصنيفات: كاشير، مبيعات، مطاعم، سائقين، عمال، محاسبين، ودليفري.
- المناطق المستهدفة: المنصورة، أويش الحجر، البدالة، البرامون، البقلية، برق العز، بدواي، شها، طناح، ميت بدر خميس، ميت مزاح، ومحلة الدمنة.
- التقديم عبر واتساب، ومشاركة الوظائف من زر مخصص.
- حفظ الوظائف على جهاز المستخدم، والإبلاغ عن الإعلانات.
- لوحة إدارة لمراجعة الإعلانات والبلاغات، وتفعيل التمييز وتوثيق صاحب العمل.
- تأكيد إداري يدوي لاستلام قيمة الإعلان المميز قبل تفعيله؛ لا توجد بوابة دفع إلكترونية مدمجة.
- إحصاء ضغطات التقديم، وتفضيلات تنبيهات الوظائف أثناء فتح الموقع.
- ربط Firebase Authentication وCloud Firestore لمشاركة الوظائف بين المستخدمين.
- ملف Manifest وأيقونة وService Worker لدعم التثبيت والتخزين المؤقت لهيكل الموقع.

## الملفات الأساسية

- `index.html`: واجهة الموقع والمنطق الأساسي.
- `manifest.json`: إعدادات تثبيت الموقع كتطبيق ويب.
- `icon.svg`: أيقونة الموقع.
- `sw.js`: تخزين مؤقت محدود لهيكل الموقع.

## النشر

يمكن نشر الملفات كصفحة GitHub Pages من الفرع `main` والمجلد الجذر. بعد كل تحديث، قد يستغرق ظهور التغيير عدة دقائق. رابط الموقع المتوقع لهذا المستودع:

https://medosalama650-sys.github.io/hoghl-dakahlia-android/

## قبل تسليم المشروع لمالك جديد

1. مراجعة قواعد Firestore وFirebase Authentication وعدم استخدام قواعد قراءة/كتابة عامة.
2. تحديث بريد الإدارة وأرقام التواصل وإعدادات Firebase إلى حساب المالك الجديد.
3. اختبار إضافة إعلان ومراجعته ونشره والتقديم عبر واتساب على هاتف فعلي.
4. التأكد من إعداد GitHub Pages، واختبار التثبيت والتخزين المؤقت بعد النشر.
5. توضيح أن التمييز يُفعّل يدويًا بعد تأكيد الدفع، وأن تنبيهات الخلفية تحتاج إعدادًا منفصلًا إذا كانت مطلوبة.

**ملاحظة:** إعدادات Firebase الموجودة في الواجهة لا تغني عن قواعد أمان صحيحة في Firebase. لا تعتبر أي ميزة مكتملة نهائيًا قبل اختبارها على النسخة المنشورة.
